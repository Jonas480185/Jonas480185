## Projekte

### [Semester Cockpit](https://github.com/Jonas480185/semester-cockpit)

Eine Web-App zur Organisation meines Studiums. Module, Klausuren, Lernblöcke und Lernfortschritt lassen sich zentral verwalten.

In meiner privaten Instanz können KI-Assistenten über **MCP** auf freigegebenen Lernkontext zugreifen und nach Lernsitzungen Rückmeldungen speichern. Dadurch bleibt der Lernstand auch über verschiedene Sitzungen und Fachchats hinweg verfügbar.

**Tech:** Next.js · TypeScript · PostgreSQL · Tailwind CSS · MCP

[Live-Demo öffnen](https://semester-cockpit-demo.vercel.app/demo) · [Repository ansehen](https://github.com/Jonas480185/semester-cockpit)

### [Menta](https://github.com/Jonas480185/menta)

Ein Ernährungstagebuch zum Erfassen von Mahlzeiten, Kalorien, Nährstoffen, Gewicht und Aktivität. Die Anwendung bietet unter anderem Lebensmittelsuche, Rezepte, Barcode-Suche und Auswertungen über längere Zeiträume.

**Tech:** Next.js · TypeScript · PostgreSQL · Drizzle ORM · Tailwind CSS

[Live-Demo öffnen](https://menta-jonas.vercel.app) · [Repository ansehen](https://github.com/Jonas480185/menta)
